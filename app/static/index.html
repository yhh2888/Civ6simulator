게임 데이터 준비 / Game data setup

이 시뮬레이터는 문명 6의 규칙 데이터를 함께 배포하지 않습니다. 처음 한 번, 내 PC에 설치된 게임에서 데이터를 읽어 로컬 색인을 만듭니다. 만든 파일은 이 폴더의 app/data에만 저장되고 어디로도 전송되지 않습니다.

This simulator does not ship Civilization VI's rule data. On first run it reads the data from the game installed on your PC and builds a local index in app/data. Nothing is uploaded anywhere.

  1. 방법 1 (권장): 게임 폴더를 바로 지정 — 아래 칸에 게임 설치 폴더를 넣고 [추출]을 누릅니다. 예: C:\Program Files (x86)\Steam\steamapps\common\Sid Meier's Civilization VI
    Option 1 (recommended): point at the game folder — enter the install folder below and press Extract.
  2. 방법 2: collect_game_data.bat 실행 — 프로젝트 폴더의 배치 파일이 게임 폴더에서 Base\Assets\Gameplay\Data와 DLC의 XML·SQL·modinfo만 골라 game_data 폴더로 복사합니다(수십 MB 이하, 아트 파일 제외). 그다음 아래 칸에 game_data 폴더를 넣고 [추출]을 누릅니다.
    Option 2: run collect_game_data.bat — it copies only the XML/SQL/modinfo files of Base\Assets\Gameplay\Data and DLC into game_data (no art). Then enter that folder below and press Extract.
  3. 확장팩(흥망성쇠·몰려드는 폭풍)과 DLC 규칙은 DLC 폴더가 있을 때만 만들어집니다. 기본 게임만 있으면 기본 규칙으로 동작합니다.
    Expansion and DLC rules are built only when the DLC folder is found; otherwise the base rules are used.

      유닛 제어 · 강제 관리

      건물은 도시 조건을, 불가사의·특수지구·시설은 선택 타일과 도시 조건을 충족해야 합니다. 불가한 항목은 사유와 함께 비활성화됩니다.

      건설자는 도심이 아닌 소속 도시의 타일에서 지을 수 있습니다. 타일·기술·행동력 조건을 만족하지 않는 시설은 선택할 수 없습니다.
